# Сайт FileManager

Публичная страница приложения и его политика конфиденциальности.
Публикуется через GitHub Pages из ветки `main`, папка `/ (root)`:
https://oasan.github.io/filemanager-site/

- `index.html` — короткая страница о приложении.
- `privacy.html` — политика конфиденциальности. Её адрес указывается
  в Play Console и в приложении — **не переименовывать и не переносить**.
  Единственный источник текста политики — этот файл.
- `assets/style.css` — стили, тёплая палитра приложения, светлая и тёмная.
- `assets/icon.webp` — значок, сжат из `../assets/app-icon/icon.png`.
- `fonts/` — Golos Text, OFL.
- `.nojekyll` — отключает обработку Jekyll.

Репозиторий публичный: ничего закрытого сюда не класть.

Локальный просмотр: `python3 -m http.server 8000` из этой папки.
