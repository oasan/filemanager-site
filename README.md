# Сайт FileManager

Публичная страница приложения и его политика конфиденциальности.
Публикуется через GitHub Pages из ветки `main`, папка `/ (root)`:
https://oasan.github.io/filemanager-site/

- `index.html` — лендинг. Стили, палитры всех тем (роли из `Color.kt`
  приложения) и скрипт — внутри файла. Оформление общее с сайтом
  «Аудиокниг»: та же дизайн-система, свои разделы.
- `img/<палитра>-<фон>/<экран>.webp` — снимки экранов, шесть тем, 600 px
  по ширине. Сжаты из PNG в `screenshotes/` (там же описание снимков):

      cwebp -q 80 -resize 600 0 screenshotes/warm-dark-browser.png -o img/warm-dark/browser.webp

- `fonts/` — Golos Text и JetBrains Mono, вариативные, OFL.
- `privacy.html` — политика конфиденциальности. Её адрес указывается
  в Play Console и в приложении — **не переименовывать и не переносить**.
  Единственный источник текста политики — этот файл.
- `assets/style.css` — стили страницы политики.
- `assets/icon.webp`, `assets/icon-cool.webp` — значки, сжаты
  из `../assets/app-icon/icon.png` и `icon-cool.png`.
- `.nojekyll` — отключает обработку Jekyll.

Кнопки «Скачать APK» в `index.html` ведут на последнюю сборку в GitHub Releases:
https://github.com/oasan/filemanager-site/releases/latest/download/filemanager.apk

## Публикация новой сборки

1. Проверить версию и подпись релизного APK (`../releases/<версия>/`).
2. В этом репозитории создать релиз с тегом `v<versionName>-<versionCode>`
   (например, `v1.0.3-3`) и описанием изменений.
3. Прикрепить APK с постоянным именем **`filemanager.apk`**.
4. Опубликовать релиз и отметить его как **Latest**. Предварительные релизы
   не использовать для кнопок сайта.
5. Обновить подпись версии в обеих кнопках (`small.version`) в `index.html`
   и опубликовать сайт. Адрес скачивания остаётся прежним.
6. Проверить скачивание по ссылке выше и подписи версии на сайте.

APK прикрепляется к релизу, в Git его не добавлять.

Репозиторий публичный: ничего закрытого сюда не класть.

Локальный просмотр: `python3 -m http.server 8000` из этой папки.
